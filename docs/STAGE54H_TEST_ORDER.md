# Stage 54h device test order

1. Install over Stage 54g.
2. Verify the launcher/app-drawer icon refreshes to the supplied round Meboard keyboard artwork.
3. Open Settings > Theme. The screen must render without a crash.
4. Verify the Meboard theme is present and select it if it is not already active.
5. Open Keyboard test and verify normal typing.
6. Verify Moonshine long-press voice returns immediately to the keyboard.
7. Verify Space long-press and incognito long-press still work.
